# Vendored Power BI project schemas

These are unmodified Microsoft JSON schemas used to validate the source-controlled
PBIP/PBIR files offline. They were copied from
[`microsoft/json-schemas`](https://github.com/microsoft/json-schemas) at commit
`f891f5bfc1ce0030aa53d805d90881a1b8b07643` on 2026-08-20.
They remain covered by Microsoft's MIT terms reproduced verbatim in
`LICENSE.microsoft-json-schemas`; the repository's own license does not replace or
alter that upstream notice.

The project files retain Microsoft's canonical `developer.microsoft.com` `$schema`
URLs. The local copies make the exact schema vintages used for this artifact auditable
without claiming that the schemas validate TMDL semantics; Power BI Desktop performs
that final model check.
